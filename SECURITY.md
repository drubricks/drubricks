# Security policy

## Drupal core and contributed modules

Drubricks runs on Drupal core and contributed modules from drupal.org (Gin Login, Masquerade, Config Log, Project
Browser, …). A security issue in any of them is reported to the **Drupal Security Team**, not here:
[How to report a security issue](https://www.drupal.org/drupal-security-team/how-to-report-a-security-issue).
Keep them up to date with Composer and follow the [Drupal security advisories](https://www.drupal.org/security).

## Code of this project

Report an issue in the code of this repository — `drubricks_core`, the `drubricks` theme and its UI kit, the
`drubricks_installer` profile, the recipes, the example modules and the scripts — as an issue in
[this repository](https://github.com/drubricks/drubricks/issues).

Projects started from Drubricks own their copy of the starter code (see `docs/client-projects.md`): fix a reported
issue in your project's code as well.
